# Campus IoT Model Management Dashboard

Separate model management interface for training, testing, and managing ML models.

## Pages

- **Upload Dataset** - Upload CSV datasets for model training
- **Train Model** - Train new models with different types and parameters
- **Test Model** - Evaluate trained models on test datasets
- **Model Registry** - View and manage trained models

## Development

```bash
npm install
npm run dev
```

Dashboard runs on **port 5174**

## Building

```bash
npm run build
npm run preview
```
